# Octofit Tracker - Frontend

React 19 frontend application built with Vite for the Octofit Tracker fitness application.

## Getting Started

### Prerequisites
- Node.js 16 or higher
- npm or yarn

### Installation

```bash
npm install
```

### Development

Run the development server with Hot Module Replacement:

```bash
npm run dev
```

The application will open in your browser at `http://localhost:3000`

### Build

Create a production build:

```bash
npm run build
```

### Preview

Preview the production build locally:

```bash
npm run preview
```

### Lint

Check code quality:

```bash
npm run lint
```
